# 什麼是盲注
有存在 SQLi 漏洞，但無法從網頁內容中取得 SQL 查詢結果或資料庫錯誤訊息，例如使用 UNION 運算子注入效果不佳，此時就可利用其它技巧取得未經授權的數據。

嚴格來說，盲注最核心的類型是「布林盲注（Boolean-Based）」；實務教材也常把時間、錯誤、帶外等間接技術一起分類說明。

| 類型                       | 判斷依據             | 典型現象          |
| ------------------------ | ---------------- | ------------- |
| 布林盲注（Boolean-Based）      | 頁面內容或狀態差異        | 有無特定字變化       |
| 時間盲注（Time-Based）         | 回應時間差異           | 條件成立時延遲秒      |
| 錯誤式盲注（Error-Based）       | 是否解發錯誤內容         | 真 / 假條件產生不同錯誤 |
| 帶外注入（Out-of-Band / OAST） | 外部 DNS / HTTP 互動 | 資料庫向指定網域發出請求  |
盲注的演練環境可以使用 PortSwigger Academy，須注意的是 Lab 中的注入都是在已知的條件下完成，但在實際的攻防中須從未知的 Schema、Table、Column 將整個數據撈出；然而在整個活動中，藉由一次次的真假判斷來取得數據的過程，效率比較低下，因此可透過 Burp Suite 中的 intruder 模組有提供 loop 的方式來完成自動化。
## 布林盲注
利用條件為真或假時，網站回應內容的差異判斷資料，例如歡迎字串。

### DBMS
當條件為真時出現一個 ＂Welcome Back!＂區塊，因此已確定可透過 Boolean-Based 來推斷結果，接下來確定 Lab 運行哪一套 DBMS，透過以下注入條件來確認：

- **PostgreSQL - current_database()=current_database()**
- **MySQL - DATABASE()=DATABASE()**
- **MS SQL - DB_NAME()=DB_NAME()**
- **Oracle SQL - SYS_CONTEXT('USERENV','DB_NAME') IS NOT NULL**
